# Практическое занятие №3 — HTTP-сервер на Go

Учебный сервер для хранения задач в памяти. Реализованы проверка состояния сервера, создание задачи, получение списка с фильтром и поиск задачи по ID. Ответы и ошибки возвращаются в JSON, запросы логируются.

Запуск из корня проекта: `go run ./cmd/server`. Сервер доступен по адресу `http://localhost:8080`. После перезапуска задачи исчезают, потому что постоянная база данных не используется. Команды проверки приведены в `requests.md`.
